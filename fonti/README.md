# Fonti di riferimento

Questa cartella contiene copie dei materiali ministeriali forniti per il progetto. I 23 file originali inclusi sono elencati in `manifest.json`, con dimensione e SHA-256.

- `Istruzioni/`: modello telematico, fascicoli, aggiornamenti e vecchio Modello 4.
- `Specifiche tecniche/`: specifiche SUC13, guida al calcolo, modifiche e schemi XSD.
- `Programma e controlli/`: avviatori JNLP pubblici. Non sono sorgenti del programma; fanno riferimento a componenti ufficiali remoti.

Il manuale commerciale SEAC 2021 non viene pubblicato e non è un requisito per iniziare. Il numero di 24 file nelle note storiche della ricognizione comprendeva anche quel manuale.

Conserva intatti i file. Versioni più recenti, se necessarie, devono essere acquisite e documentate separatamente. Il nome del file non prova la versione del contenuto e la conformità XSD non esegue automaticamente le annotazioni applicative.

Esegui dalla radice: `python scripts/verifica_materiali.py`.
